# POLYMAZE Champions League

Draw page for the **POLYMAZE** robotics competition, styled after the Champions League league-phase draw.

## What it does

- Takes 12 team names in two tiers (typed in or imported), names must be unique
- Runs the draw
- Produces the league-phase fixtures with maze assignments and a schedule

## Use it

Static page with no build step. Open `index.html` in a browser.

| File | What |
|---|---|
| `index.html` | screens |
| `app.js` | draw, maze assignment, schedule |
| `styles.css` | styles |
| `Design-System/` | brand assets |

Related: [POLYMAZE website](https://github.com/puIad/polymaze-website).
